How to use

1. Deploy this app on an HTTPS website, then start the signaling server.

2. One person creates a room and shares the invite link. The other person opens it and joins.

3. Allow camera and microphone access when the browser asks.

Note: This demo supports two participants per room. For reliable calls across restrictive networks, configure a TURN server.
